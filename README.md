# The C1 Edition

Личный интерактивный учебник английского: от B2 к C1 за 26 недель.

- Ежедневный урок 30–50 минут: слова, грамматика, текст, речь
- Интервальное повторение слов и конструкций
- Прогресс хранится в браузере (Настройки → Резервная копия)

Структура:
- `index.html`, `css/style.css`, `js/app.js` — движок
- `js/course.js` — карта курса (26 недель)
- `js/lessons/wXXdY.js` — уроки
